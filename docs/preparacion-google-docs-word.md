# Preparación para Google Docs y Word

## Objetivo

Preparar el proyecto para generar documentos editables.

## Salida esperada

- Google Docs editable.
- Archivo Word (.docx), cuando el flujo lo permita.

## Variables

- ciudad
- fecha
- entidad
- nombre
- documento
- correo
- asunto
- hechos
- solicitud
- anexos

## Reglas

- No incluir datos sensibles.
- No incluir tokens.
- No incluir claves.
- Mantener el documento editable.
