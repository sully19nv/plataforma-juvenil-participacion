# Configuración de cuentas y tokens

## n8n

- Crear cuenta.
- Crear Workflow.
- Crear Webhook.
- Guardar la URL en `.env`.

## DeepSeek

- Crear cuenta.
- Crear API Key.
- Guardarla únicamente en n8n.
- Nunca subirla a GitHub.

## Google

- Crear Google Sheets.
- Autorizar Google Docs.
- Autorizar Google Drive.

## Telegram

- Crear un bot con BotFather.
- Guardar el token en n8n.
- Obtener el chat_id.

## Reglas

- No subir `.env`.
- No subir credenciales.
- No subir tokens.
- No usar datos reales.
